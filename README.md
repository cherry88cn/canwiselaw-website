# CanWise Law website

Editable page modules and blog articles are in [`content`](content/README.md). Changes committed there on `main` are automatically rebuilt for GitHub Pages.

Static website for CanWise Law, prepared for GitHub Pages.

The site contains the current public pages migrated from Hostinger Website Builder. It runs without Hostinger runtime dependencies.

## Local build

Run `node scripts/build-site.mjs` from the repository root. The build uses only files stored in this repository.
